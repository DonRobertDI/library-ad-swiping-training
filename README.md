# Ad Swiping and Discovery Workflow

A responsive Next.js training guide built from the Library Operations workflow document and its original screenshots.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

```bash
npm install -g vercel
vercel login
vercel
vercel --prod
```

Run the commands from this project directory. Vercel detects Next.js automatically; no additional build configuration is required.
